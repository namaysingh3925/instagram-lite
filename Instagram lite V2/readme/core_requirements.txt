Functional Requirements:

Scope

The mandatory version of Instagram Lite contains the following modules:

1. User 
   Register, Login, Profile

2. Posts 
   Create, View, Update, Delete

3. Feed	
   View posts from users

4. Likes	
   Like / Unlike posts

5. Comments	
   Add / View / Delete comments	

6. Follow	
   Follow / Unfollow users	

7. Profile	
   User's posts, followers, following	

8. Authentication, Authorization and Validation
